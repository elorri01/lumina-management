# Web marca personal / LLC

1. Abre `config.js` y cambia nombre, iniciales, nombre legal de la LLC, estado, dirección, email y redes.
2. (Opcional) Pon tu foto: guarda `foto.jpg` aquí y sigue el comentario en la sección "About" de `index.html`.
3. Subir a Vercel: arrastra esta carpeta en vercel.com/new (o `npx vercel` desde la carpeta). No necesita build.
4. Conecta tu dominio en Vercel → Settings → Domains.
